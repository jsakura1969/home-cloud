痰を出しやすくする方法

強い咳を何度もくり返すより、「ゆるめる → 動かす → 出す」の順に進める方が体力を使いません。

出す

ハフィング

  1. 背すじを伸ばして座り、少し大きめに息を吸う
  2. 口を「ハ」の形に開けたまま
  3. 窓ガラスを曇らせるように「ハーッ」と素早く強く吐き切る
  4. 1〜2回行い、痰がのどまで来たら軽く咳をして出す

咳より喉や気道への負担が少なく、体力が落ちている時にも向いています。

動かす

アクティブサイクル呼吸法

楽な呼吸 → 深呼吸 → ハフィングを1セットとして、痰が出るまでくり返す方法です。リハビリの現場でよく使われます。

ゆるめる

水分をこまめにとる

体の水分が足りないと痰は粘り、張り付きやすくなります。常温の水や白湯を少しずつ、1日1.5〜2Lを目安に。

心臓病・腎臓病などで水分制限を受けている人は、医師の指示に従ってください。

ゆるめる

湿度と蒸気

  • 部屋の湿度を50〜60%に保つ
  • 入浴やシャワーの湯気をゆっくり吸う
  • 蒸しタオルを口元に当てて呼吸する（やけどに注意）
  • 寝る時はマスクでのどの乾燥を防ぐ
動かす

姿勢を変える（体位ドレナージ）

痰のたまっている側を上にして横向きに寝ると、重力で痰が太い気管へ移動しやすくなります。5〜10分を目安に。

食後1時間以内は避けてください。心臓病・逆流性食道炎・頭を低くできない病気がある人は医師に相談を。

原因を減らす

鼻からの痰（後鼻漏）

鼻水がのどに流れて痰になっている場合は、こまめに鼻をかむ・生理食塩水での鼻うがいが役立ちます。朝に痰が多く、鼻づまりがある人は耳鼻科も選択肢です。

薬

去痰薬を使う

市販薬にも痰を出しやすくする成分（カルボシステイン、アンブロキソール、ブロムヘキシンなど）があります。持病や服用中の薬がある人は薬剤師に相談してください。

避けたいこと

逆効果になりやすいこと

  • 喫煙・受動喫煙（痰の量が増えます）
  • 痰があるのに自己判断で咳止めを使う（痰が出しにくくなることがあります）
  • 出ない痰を強い咳で何度も出そうとする
  • アルコールやカフェインのとりすぎ（脱水ぎみになります）
